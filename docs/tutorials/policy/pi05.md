# PI0.5

## Environment Setup

We use [uv](https://docs.astral.sh/uv/) to manage Python dependencies. Once uv is installed, run the following command from the RoboSynChallenge root:

```bash
uv sync --locked --python 3.12
```

See [Installation](../../getting_started/installation.md) for Docker and local uv setup.

## Prepare OpenPI Data for Training

The original OpenPI/JAX trainer and Orbax checkpoint format run in the root Python 3.12 environment. LeRobot 0.6.1 reads v3.0 dataset frames, camera streams, and task prompts. The OpenPI observation and action transforms, normalization assets, and model parameter layout still apply to existing runs.

If you want to train on multiple datasets together (e.g., multi-task, mixed training with simulated and real data), merge compatible datasets with the [lerobot-edit-dataset tool](https://huggingface.co/docs/lerobot/using_dataset_tools) or `launch/collect_combined_dataset.sh`.

### Train with Downloaded Data

Download instructions are in <a href="../download_data.html">Download Data</a>. For a downloaded `click_bell` simulation dataset, run stats and training on the same local directory:

```bash
dataset_root=lerobot_dataset/han-xudong/cobotmagic_Sim_click_bell
repo_id=han-xudong/cobotmagic_Sim_click_bell
bash launch/openpi.sh pi05 stats --config-name pi05_base_robosynchallenge_full \
  --dataset-root "$dataset_root" --repo-id "$repo_id" --asset-id cobotmagic
bash policy/pi05/finetune.sh pi05_base_robosynchallenge_full click_bell 0 \
  --data.dataset-root "$dataset_root" --data.repo-id "$repo_id" \
  --data.assets.asset-id cobotmagic --batch-size 1
```

## Write the Corresponding `train_config`

In `policy/pi05/src/openpi/training/config.py`, `_CONFIGS` includes `pi05_base_robosynchallenge_full`. The RoboSynChallenge configuration uses `han-xudong/cobotmagic_Sim_click_bell` at `v3.0` by default. The OpenPI base weights use `OPENPI_DATA_HOME`.

## Finetune model

```bash
export OPENPI_DATA_HOME=/data/openpi-cache
bash launch/openpi.sh pi05 stats --config-name pi05_base_robosynchallenge_full \
  --asset-id cobotmagic
bash policy/pi05/finetune.sh pi05_base_robosynchallenge_full my-run 0 \
  --data.assets.asset-id cobotmagic --batch-size 1
```

Select another Hub dataset with `--repo-id` for stats and `--data.repo-id`
for training. For a local dataset, point `--dataset-root` or
`--data.dataset-root` at the directory containing `meta/info.json`.
Compute normalization stats with the same dataset and asset ID used in training.

### Resume an existing run

Pass the original experiment name, config, normalization asset ID and checkpoint base directory. Increase `--num-train-steps` to the desired total step count.

```bash
bash policy/pi05/finetune.sh pi05_base_robosynchallenge_full my-run 0 \
  --resume --num-train-steps 40000 --data.dataset-root datasets/task-dataset \
  --data.repo-id local/robosynchallenge --data.assets.asset-id cobotmagic --batch-size 1
```

## Eval on RoboSynChallenge

```bash
bash policy/pi05/eval.sh click_bell clear pi05_base_robosynchallenge_full my-run 0 \
  --checkpoint_id 20000 --headless true --renderer fast-rt
```

The default lookup is `policy/pi05/checkpoints/<config>/<experiment>/<step>`. Use `--checkpoint_path` for a checkpoint stored elsewhere and `--asset_id` if the checkpoint contains several normalization assets.
